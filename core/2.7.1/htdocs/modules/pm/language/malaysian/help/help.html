Bantuan: Pemesejan Peribadi

-----Kandungan Bantuan ----------

PENERANGAN

Modul PM adalah untuk pemesejan peribadi antara pengguna

PASANG/NYAHPASANG

Tiada langkah khas perlu, ikut proses pemasangan standard – ekstrak folder /pm ke dalam direktori ../modules. Pasangkan modul melalui Admin -> Modul Sistem -> Modul. pautan

Arahan terperinci tentang memasang modul tersedia dalam Operasi XOOPS Manual

ARAHAN OPERASI

Untuk menyediakan modul ini anda perlu:

  • Anda memasukkan Peti Masuk anda terus dari halaman depan, atau dengan mengklik pada pautan atas "Pergi ke modul" di kawasan Pentadbiran PM.
  • Konfigurasikan pilihan anda untuk modul (lihat "Keutamaan") dan secara pilihan blok PM jika anda berhasrat untuk menggunakannya (lihat "Blok").
  • Anda boleh melakukan pemadaman besar-besaran mesej anda dengan menggunakan tab "Prune" Messages".
