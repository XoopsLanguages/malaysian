Memasang XOOPS

Pemasangan kali pertama

Prakata:

XOOPS ialah sumber terbuka Sistem penerbitan Web Berorientasikan Objek yang ditulis dalam PHP. Ia adalah alat yang ideal untuk membangunkan laman web komuniti dinamik kecil hingga besar, portal intra syarikat, portal korporat, weblog dan banyak lagi.

XOOPS dikeluarkan di bawah terma Lesen Awam Am GNU (GPL) versi 2 atau lebih tinggi, dan percuma untuk digunakan dan diubah suai. Ia adalah percuma untuk mengagihkan semula selagi anda mematuhi syarat pengedaran GPL.

Keperluan

  • Pelayan WWW (Apache, NGINX, IIS, dsb)
  • PHP 8.2 atau lebih tinggi, 8.4+ disyorkan
  • MySQL 5.7 .8 atau lebih tinggi, MySQL 8.4.5+ disyorkan

Sebelum anda memasang

  1. Sediakan pelayan WWW, PHP dan pelayan pangkalan data dengan betul.
  2. Sediakan pangkalan data untuk tapak XOOPS anda.
  3. Sediakan akaun pengguna dan berikan pengguna akses kepada pangkalan data.
  4. Jadikan direktori dan fail boleh ditulis: %s
  5. Untuk pertimbangan keselamatan, anda dinasihatkan untuk mengalih keluar dua direktori di bawah akar dokumen dan tukar nama folder: %s
  6. Cipta (jika belum ada) dan jadikan direktori boleh ditulis: %s
  7. Hidupkan kuki dan JavaScript pelayar anda.

Memasang secara setempat

Jika anda menjalankan persekitaran tempatan untuk pembangunan atau ujian, pastikan anda mempunyai persekitaran sebelumnya keperluan dipenuhi. Setelah ini selesai, salin kandungan htdocs direktori (daripada XOOPS fail pengedaran) ke laluan dokumen akar persekitaran web anda. Setelah fail disalin di sana, anda boleh memulakan pemasangan dengan menghalakan pelayar anda ke "http://laman web anda.com". Ini akan memulakan proses pemasangan.

Memasang pada platform yang dihoskan

Jika anda menjalankan dalam persekitaran yang dihoskan, buka pek fail XOOPS secara setempat atau pada pelayan jika anda mempunyai akses shell (iaitu SSH). Setelah selesai, pastikan anda mengalihkan atau menyalin semua fail XOOPS daripada fail htdocs direktori ke direktori web akar anda (pembekal anda biasanya menyediakan lokasi ini dengan arah). Setelah fail disalin di sana, anda boleh memulakan pemasangan dengan menghalakan penyemak imbas anda "http://laman web anda.com". Ini akan memulakan proses pemasangan.

Meneruskan pemasangan

Cuma ikut arahan langkah demi langkah dalam pemasang.
