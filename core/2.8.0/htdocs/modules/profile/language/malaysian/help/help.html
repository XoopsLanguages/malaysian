PENERANGAN

Modul Profil adalah untuk mengurus medan profil pengguna tersuai.

PASANG/NYAHPASANG

Tiada langkah khas perlu, ikut proses pemasangan standard – ekstrak folder /profile ke dalam direktori ../modules. Pasang modul melalui Pentadbir -> Modul Sistem -> Modul.

Arahan terperinci tentang memasang modul tersedia dalam Manual Operasi XOOPS

ARAHAN OPERASI

Untuk menyediakan modul ini anda perlu:

  • Konfigurasikan pilihan anda untuk modul (lihat 'Keutamaan') dan secara pilihan blok Profil jika anda berhasrat untuk menggunakannya (lihat 'Blok').
  • Edit Kategori sedia ada atau tambah yang baharu.
  • Edit Medan sedia ada atau tambah yang baharu. Di sini anda boleh menentukan medan mana yang akan kelihatan dalam kategori mana, dan jika ia akan kelihatan semasa pendaftaran pengguna.
  • Tentukan susunan langkah Pendaftaran.
  • Dan akhirnya, anda boleh menetapkan kebenaran untuk medan individu - yang mana boleh diedit, yang mana boleh dicari.

Langkah anti-Spam

Untuk meminimumkan pendaftaran spam, lakukan perkara berikut:

  • pergi ke modul Pelindung dalam Pentadbir, pergi ke Keutamaan, dan kemudian di bahagian bawah, pada pilihan ini: "Hentikan Spam Forum" Menyemak data POST terhadap pengirim spam yang didaftarkan pada pangkalan data www.stopforumspam.com.
    Tetapkannya kepada "Haramkan IP (tiada had)"

  • dalam /class/captcha/config.php, pastikan mod ditetapkan sebagai "teks":

    return $config = array(
    'disabled' => false, // Lumpuhkan CAPTCHA
    'mode' => 'teks', // mod lalai, anda boleh memilih 'teks', 'imej', 'recaptcha'(memerlukan kunci api)
    'name' => 'xoopscatcha', // nama captcha
    'skipmember' => true, // Langkau semakan CAPTCHA untuk ahli
    'maxattempts' => 10, // Percubaan maksimum untuk setiap sesi
    );

  • Dalam modul Profil, pergi ke Pentadbir dan dalam langkah Asas yang terletak di:
    /modules/profile/admin/step.php?id=1
    tetapkan "Simpan selepas berhenti" kepada "Tidak"


  • Dalam Keutamaan Profil, tetapkan Pilihan "Gunakan Captcha selepas langkah Pendaftaran kedua" kepada "Ya" (ia adalah lalai)
