Bantuan: Penyelenggaraan

Penerangan

Penyelenggaraan menyediakan beberapa fungsi asas untuk membantu anda dalam mengekalkan pemasangan XOOPS anda dan memastikannya sihat:

- folder cache bersih
- kosongkan jadual sesi
- laksanakan penyelenggaraan jadual pangkalan data (analisis, semak, optimumkan dan baiki)

Anda juga boleh melakukan "Buang" keseluruhan pangkalan data atau jadual individu untuk tujuan sandaran.
